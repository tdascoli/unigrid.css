Responsive Behavior

The module grid reduces columns at each breakpoint:

Breakpoint Columns Module (vw) Gutter (vw) Outer Margin Class Prefix
≥1600px (xl) 12 6.8966 1.1494 2.2989 .ug-module--{h}x{w}
1300–1599px (lg) 8 10.4478 1.4925 2.9851 .ug-module--lg-{h}x{w}
1024–1299px (md) 6 14.0351 1.7544 3.5088 .ug-module--md-{h}x{w}
640–1023px (sm) 4 21.2766 2.1277 4.2553 .ug-module--sm-{h}x{w}
≤639px (xs) 3 28.5714 2.3810 4.7619 .ug-module--xs-{h}x{w}

Apply responsive overrides: .ug-module--2x4 .ug-module--lg-2x3 .ug-module--sm-1x4 .ug-module--xs-1x3
