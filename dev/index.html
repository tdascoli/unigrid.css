Unigrid

CSS Framework / Dev Environment

About

A CSS grid framework inspired by Massimo Vignelli's Unigrid system for the National Park Service. Built with SCSS, native CSS Grid, and BEM naming.

The Unigrid is a standardized graphic and production system. Its 10 basic formats (A1–A4, A6, B1–B4, B6) are all built from a single panel unit of 99 × 210 mm, based on DIN/ISO proportions (1:√2).
