7. Accessibility Checklist

  • Labels: Every input has a visible <label> via Bootstrap's form-floating pattern.
  • Error announcements: role="alert" on .invalid-feedback for live region announcements.
  • ARIA: aria-invalid, aria-describedby, aria-required, and aria-disabled are set appropriately.
  • Focus: outline: 3px solid with outline-offset: 2px — visible in forced-colors (High Contrast) mode.
  • Touch targets: All inputs have min-height: 44px and min-width: 44px (WCAG 2.5.8).
  • Color independence: Error/success states use icons and text, not color alone.
  • Reduced motion: Transitions respect prefers-reduced-motion: reduce.
  • Mobile keyboards: inputmode attributes trigger appropriate soft keyboards.
